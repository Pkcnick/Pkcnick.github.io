# Personal Academic Website

This is a simple static website for GitHub Pages.

## Files

- `index.html` — main website content
- `styles.css` — styling
- `.nojekyll` — tells GitHub Pages not to process the site with Jekyll
- `assets/` — place your CV PDF and profile photo here

## How to publish on GitHub Pages

1. Create a GitHub account if you do not already have one.
2. Create a new public repository named exactly:

   `yourusername.github.io`

   Replace `yourusername` with your GitHub username.

3. Upload all files from this folder into the repository root.
4. Go to the repository:
   Settings → Pages
5. Under "Build and deployment", select:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: /root
6. Save.
7. Your website will appear at:

   `https://yourusername.github.io`

## Important edits before publishing

In `index.html`, replace:

- `your.email@example.com`
- Google Scholar link
- GitHub link
- LinkedIn link
- ORCID link
- DOI / journal links
- arXiv links
- project links

Also replace:

`assets/Prashant_Kumar_Choudhary_CV.pdf`

with your actual CV PDF file.
